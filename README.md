# # ศูนย์รวมข้อมูลท่องเที่ยวชุมชนจังหวัดบุรีรัมย์

เว็บไซต์ 3 หน้า: index.html (หน้าแรก), places.html (รายการสถานที่ + สภาพอากาศจาก Open-Meteo), contact.html (แบบฟอร์มพร้อมตรวจสอบข้อมูล)

## เหตุผลที่เลือกใช้ไลบรารี
- **Font Awesome**: ใช้ไอคอนเมนู ปุ่มสลับโหมด และสถานะ loading ได้ทันทีโดยไม่ต้องทำไฟล์ภาพเอง ช่วยให้ปุ่มสื่อความหมายชัดและโหลดเร็ว
- **Google Fonts (Prompt)**: ฟอนต์เดียวที่รองรับภาษาไทยครบทุกน้ำหนัก ทำให้ตัวอักษรอ่านง่ายและสอดคล้องกันทั้งเว็บ

## ฟังก์ชัน JavaScript (script.js)
initMenu (hamburger), initTheme (โหมดสว่าง/มืด), initFilter (ค้นหา/กรอง), initForm (validation), loadWeather (เรียก API)
